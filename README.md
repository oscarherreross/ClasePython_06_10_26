# Fundamentos de Python · Python 2

Apuntes y ejercicios resueltos de la sesión **Python 2** del Bloque 1 (Fundamentos) del Máster en Desarrollo Web, IA aplicada y DevOps. Todo el código está en [`script.py`](script.py), comentado y listo para ejecutar.

## Contenido

1. **Listas, tuplas y sets:** colecciones mutables, inmutables y sin duplicados.
2. **Diccionarios anidados:** acceder a listas y diccionarios dentro de un diccionario.
3. **Condicionales:** validar la longitud de una contraseña.
4. **Bucle `for`:** recorrer listas elemento a elemento.
5. **Bucle `while`:** contadores, bucles anidados y números divisibles entre 5 y 7.
6. **Lista de diccionarios:** filtrar productos por precio y stock.
7. **Funciones:** `def`, `return`, docstrings y parámetros con valor por defecto.
8. **Ejercicios de funciones:** promedio, áreas, contar caracteres y letras, comparar números, cuenta atrás y mensajes de pedidos.
9. **Funciones lambda:** funciones anónimas de una sola expresión.
10. **Debugging:** cómo usar el debugger de VS Code y cómo corregir un `KeyError`.

## Cómo ejecutarlo

```bash
python script.py
```

Solo necesitas Python 3; no hace falta instalar ninguna librería.
